# mostsport_apk — конфигурация туннеля Mostsport

Этот репозиторий — **админ-панель и источник конфигурации** для встроенного туннеля
приложения Mostsport (сборка `ligasport_gate.apk`). Приложение при запуске (когда
прямой доступ к сайту закрыт) скачивает отсюда `gate-config.json` и работает по нему.

## Что в репозитории

| Файл | Назначение |
|---|---|
| `gate-config.json` | Живой конфиг: приоритетные ключи, адрес подписки, фильтры стран |
| `admin.html` | Админ-панель — открой в любом браузере, правь конфиг, жми «Сохранить» |

## Как приложение использует конфиг

1. При старте проверяется прямой доступ к `direct_url`. Открылся — туннель не нужен.
2. Конфиг берётся по цепочке (каждый шаг ограничен по времени, зависаний нет):
   **GitHub (3 зеркала параллельно) → кэш в приложении → копия, вшитая в APK**.
   Зеркала: `raw.githubusercontent.com`, `cdn.jsdelivr.net`, `raw.githack.com`.
   Если кэш моложе `ttl_hours` — сеть не трогается вообще.
3. Подключение идёт по цепочке: **приоритетные ключи по порядку** (сейчас —
   туркменский сервер первым) → лучшие по задержке серверы из подписки, прошедшие
   фильтр `allow`/`ban` → если ничего не поднялось, приложение открывается напрямую
   без VPN.
4. После подключения конфиг и подписка обновляются в фоне через туннель —
   смена ключей доходит до устройств без переустановки.

## Настройка админ-панели (один раз)

1. Создай fine-grained токен: GitHub → Settings → Developer settings →
   Fine-grained tokens → Generate. Repository access: **только этот репозиторий**,
   Permissions → Contents: **Read and write**.
2. Скачай `admin.html` (кнопка Raw) и открой в браузере, или включи GitHub Pages
   (Settings → Pages → ветка `main`) и открой `https://<owner>.github.io/mostsport_apk/admin.html`.
3. Вставь токен, нажми «Загрузить конфиг». Токен можно запомнить в этом браузере
   (localStorage) — галочка под полем.

## Ротация ключей (типовой сценарий)

1. Открой панель → «Загрузить конфиг».
2. Замени строку в «Приоритетные ключи» на новый `vless://...`
   (или добавь второй строкой — он будет запасным).
3. «Проверить подписку» — убедись, что фильтры пропускают живые серверы.
4. «Сохранить на GitHub». Готово: устройства подхватят в течение `ttl_hours`
   или сразу при следующем запуске через туннель.
5. Ошибся — «История изменений» → «Откатить в форму» → «Сохранить».

## Поля gate-config.json

| Поле | Смысл |
|---|---|
| `version` | Растёт с каждым сохранением (для порядка и отладки) |
| `updated_at` | Unix-время сохранения, ставится панелью |
| `ttl_hours` | Сколько часов кэш считается свежим (1–168) |
| `direct_url` | Адрес проверки прямого доступа |
| `sub_url` | Подписка v2rayNG (формат массива конфигов) |
| `priority` | Массив `vless://` — пробуются первыми, в порядке списка |
| `allow` | Подстроки (флаги/города): только эти страны проходят из подписки |
| `ban` | Подстроки, выкидываемые до allow |
| `connect_timeout_sec` | Таймаут подъёма туннеля на один сервер (5–30) |
| `max_ranked` | Сколько серверов из подписки пробовать после приоритетных (1–6) |

## Важно

- `app` должно быть `"mostsport-gate"` — иначе приложение проигнорирует файл.
- Репозиторий публичный: не клади сюда ничего, кроме конфига и панели.
  Ключи в `priority` по определению доступны тому, кто вытащит APK, — это не секрет,
  но и публиковать ссылку шире нужного не стоит.
- jsDelivr-зеркало кэширует до 12 часов — основной канал `raw.githubusercontent.com`,
  он обновляется почти сразу.
